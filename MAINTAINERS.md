# Maintainers

RoundForge is maintained in public.

## Primary maintainer

- [@Abdulh3](https://github.com/Abdulh3) — project direction, architecture, code review, issue triage, releases, security coordination, documentation, and CI/QA maintenance.

## Maintainer principles

- Changes to lifecycle semantics should include a deterministic regression scenario.
- Server-authoritative invariants take priority over convenience APIs.
- Breaking pre-1.0 API changes should be documented in `CHANGELOG.md`.
- Security-sensitive reports should follow `SECURITY.md` rather than public issue disclosure.
- AI-assisted changes are welcome, but maintainers remain responsible for review, tests, and the final merge decision.

As the contributor base grows, additional core maintainers can be added based on sustained technical contributions and review participation.
