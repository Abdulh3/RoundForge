# Code of Conduct

RoundForge aims to be a constructive, technically rigorous open-source project.

## Expected behavior

- Be respectful and specific when discussing code and design.
- Critique ideas and implementations, not people.
- Assume good intent while still asking for evidence and reproducible tests.
- Welcome contributors with different levels of Roblox, Luau, testing, and AI-assisted development experience.
- Keep security-sensitive details private until a fix is available.

## Unacceptable behavior

Harassment, discrimination, personal attacks, deliberate disruption, doxxing, or publishing private security details are not acceptable.

## Enforcement

The maintainer may edit or remove comments, close discussions, reject contributions, or restrict participation when necessary to protect the project and its contributors.

For conduct concerns involving the maintainer, use GitHub's platform reporting tools when appropriate.
